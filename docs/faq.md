# ❓ FAQ

[← назад к курсу](../README.md)

**Зачем писать свой харнес, если есть фреймворки?**
Чтобы понимать, что фреймворк делает за тебя. После курса любой фреймворк (Claude Agent SDK, OpenAI Agents SDK, smolagents, LangGraph) читается за вечер, и ты сам решаешь, нужен ли он. Многие продуктовые команды в итоге пишут свой тонкий цикл — он короткий, а контроль над контекстом важнее удобства.

**Какую модель брать?**
Для курса — любую с поддержкой tool use. Для отладки удобно иметь две: сильную облачную (как эталон) и дешёвую или локальную (для экспериментов). Выбирай не по рейтингам, а по **своему eval-набору** (модуль 7): доля успехов, шаги, стоимость. Id моделей меняются — бери актуальные со страницы провайдера и храни в переменной окружения.

**Можно ли пройти курс бесплатно?**
Да. Все уроки работают на сценарной модели без ключа. Для реальных экспериментов — локальные модели через [Ollama](https://ollama.com) (`LLM_PROVIDER=openai LLM_BASE_URL=http://localhost:11434/v1`). Учитывай, что маленькие локальные модели заметно хуже вызывают инструменты — это тоже полезный урок.

**Сколько стоит курс на облачной модели?**
Обычно единицы долларов: уроки короткие. Дорого становится в модуле 7 (много прогонов) — начинай eval'ы на дешёвой модели.

**Почему Python и без зависимостей?**
Чтобы ничего не скрывало механику. HTTP-запрос, SSE, JSON Schema, журнал — всё видно в коде. В своих проектах бери официальные SDK провайдеров — они добавляют ретраи, типы и удобства.

**Почему разбирается LearnHarness, а не Claude Code или Cursor?**
LearnHarness — open-source с подробной документацией архитектуры, где каждое решение объяснено. Это редкость. Плюс у него нетипичный домен (обучение), на котором хорошо видны общие принципы: два агента, план, client-side инструменты, граф знаний. Другие открытые харнесы перечислены в модуле 8.

**Нужен ли ML / математика?**
Нет. Курс — про инженерию вокруг модели. Понимание того, что модель предсказывает токены и стоит денег за токен, достаточно.

**Агенты — это надёжно для продакшена?**
Надёжно ровно настолько, насколько надёжен харнес: лимиты, подтверждения, песочница, evals, трассировка. Модель ошибается — харнес должен сделать ошибку дешёвой и обратимой.

**Как это связано с работой?**
Роли: AI engineer, LLM engineer, applied AI, agent engineer, а также обычный бэкенд в командах, встраивающих агентов. Спрашивают: агентный цикл, tool calling, context engineering, RAG, evals, стоимость, безопасность. Портфолио: 1–2 доведённых агента с eval-цифрами и разбор чужого харнеса.
